# S0 从零研究规范

少参数、稳定性、简单有效优先。本轮仅两个方法各五个N，方法选择也属于模型选择自由度；禁止观察结果后增加候选、扩大范围或加第二参数。

旧专项内容保存在`docs/archive/legacy_kalman_audit/`，状态为 **SUPERSEDED - NOT USED IN NEW MODEL DESIGN**。归档不进入导入路径，不执行其脚本，不读取其模型/特征/结果。唯一复用资产是用户指定SHA256对应的六列原始OHLCV。

本轮只运行2020—2021训练。原始快照允许对2020—2023做时间和零成交量结构核验，但2022/2023在送入模型之前截掉，不计算其斜率、信号、交易或绩效。2024+禁读。
四年都被旧策略研究使用过，不得称为完全未见独立样本外。2022为冻结后的历史验证、2023为后续历史检验，须待负责人审阅本轮、确定方法和N并生成冻结记录后才能执行。不得根据验证差重新选择N。

登记配置固定10组、成本、公共起点、资金和末端口径。不自动排名或宣布最佳，不写入获胜参数，不生成候选冻结记录。本轮无额外成本场景或参数细化。
逐候选报告净利润、多空贡献、回撤、PF、Sharpe、Sortino、胜率、笔数、持仓时长、盈利月比例、年/月收益、top1/5/10盈利交易贡献、成本拖累和离散邻域表现。
邻域仅指本方法既定网格的相邻N与自身，间距不均；端点证据有限，不能外推。方法汇总对五个既定N等权描述，不当作组合收益或方法排名。

权益基于每15分钟close MTM，初始10000纳入回撤峰值。年度/月度按开盘标签所属期间累计MTM增量，年末最后close的MTM归其K线开盘年。PF、胜率、平均持仓只含已平仓，整笔归实际退出期，跨期与MTM口径不同。
日收益=日MTM增量/固定10000，rf=0，Sharpe用样本SD及sqrt365；Sortino分母为所有日收益负部RMS。盈利月比例分母包含全部训练月份（2020-01从公共起点起为部分月）。
费用与滑点归发生时；毛收益用实际数量加回实际费用和滑点，不另跑无成本优化。topK依赖度用已平仓盈利之和作分母，删除topK只是描述性扣除，不是可执行反事实。
所有10组完整重复运行，对账逐笔、方向、年/月、成本与权益，执行公式、时序和未来扰动测试。记录配置/数据/代码哈希、日志、CSV、图表、Git提交；本地/远程一致后停止。
