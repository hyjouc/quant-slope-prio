# S1.1 Trade Anatomy：只分析既有2020—2021账本

基准：fd6658dbde9d046488577062dc53b84ef621c4bf。研究对象仅B_ols_N64和B_ols_N96，不重新比较参数，不选新模型。

运行：

```powershell
python -m pytest -q
python experiments/s1_trade_anatomy/run_analysis.py
python tools/verify_s1_anatomy.py
```

本机补充依赖在`.deps`，可设置`$env:PYTHONPATH = "$PWD\.deps"`。依赖沿用S0 requirements，不修改任何S0文件。

先核对S0清单与指定Git提交的账本/配置字节，再校验行情SHA256；任一不一致立即停止。新统计仅获得2020—2021六列原始OHLCV和原有账本，不调用任何估计器、信号生成或执行器。
既有交易重估只用于逐K线多空贡献、MTM风险和与S0权益对账，不生成新交易、不改变数量或费用。

MAE/MFE以实际入场fill为锚点，包含入场K线至退出前一根的完整高低价及退出原始open；排除退出bar其后high/low/close，不推测盘中先后。原始价格路径与实际退出滑点分开，费用不混进MAE/MFE。
回吐分别报告价格口径与含退出滑点执行口径，不将最大浮盈当可兑现利润。期末持仓单独输出，不混入已平仓分布；MTM账户风险包含持仓。
持仓分组固定[0,1)、[1,2)、[2,4)、[4,8)、[8,16)、[16,32)、[32,∞)小时。收益集中度固定top1/5/10/20。所有分组都是描述性，不筛选退出参数。
连亏按退出时间，净收益≥0终止；方向序列只看该方向。日/周/月为UTC MTM增量，沿S0开盘标签归属；周为周一至周日。
水下期从前一权益峰值至恢复，时间用实际15分钟close，未恢复时长在2021末右删失。最长水下期和最大深度可不是同一事件，均分别报告。

输出：`experiments/s1_trade_anatomy/s1_trade_anatomy_report.md`及所需7项CSV、6类图表、日志和SHA256清单；另保留期末仓位、top20路径、集中度、每条亏损串/频数、所有日周月MTM、回撤事件和多空贡献曲线，支持逐笔追溯。
本轮没有随机性检验、因果识别或止损回测，不根据MAE分位数宣布阈值。只提出单一风险研究方向，等待负责人审阅后才可能进入S1.2。
