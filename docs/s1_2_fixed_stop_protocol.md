# S1.2：仅增加固定价格止损L

本轮以S0 N64为冻结无止损对照，仅运行L=[1%,2%,3%,4%,5%,6%]及无止损，共七组2020—2021训练，不运行N96新参数搜索。
S0原公式、N、信号、启动时间、手续费/滑点/资金/固定名义及配置不改。所有S0/S1.1已有跟踪文件与提交476be2cb349f85732a498e4bd0a7ddefdd44432b逐字节核对，新代码隔离到新模块。
无止损扩展器必须先与冻结S0执行器逐笔、逐事件、逐K线精确一致，再对照已保存CSV的交易、费率费用、权益与回撤；任何失败立即停，不得运行L组。

## 唯一新增参数与事件顺序

多头stop=实际入场fill×(1−L)，空头stop=实际入场fill×(1+L)。L为价格比例，不是杠杆后保证金亏损比例；每次重入基于新fill重新固定止损，无移动或跟踪。

1. 已有仓位在open穿越或等于stop，先按raw open退出，再计不利滑点。该open不重入；即使同一边界有新反向信号，最早下一根open才可入场。
2. 若无gap-stop，先按上一根原斜率信号执行正常退出、反向开仓。此前已在open退出的仓位不使用本根后续极值判断止损。
3. 对open之后的持仓（含当根新仓），不利high/low触及stop，按raw stop加不利退出滑点平仓；同根不再入场。
4. 止损后下一根open按上一close的原信号，可同向重入或新方向开仓；无冷却、确认、过滤。无效信号不产生新订单，保护止损仍生效。

盘中确切触发时刻未知，bar-open仅为时间标签，precision=within_15m_unknown；持仓小时数保存下界与上界，不能称精确盘中时长。固定止损无止盈，因此不需要假造同根high/low先后。
跳空及滑点可能使损失超过2000×L，保证金约2L也不是严格保证。未建交易所强平、资金费、盘口或延迟模型。

## 原大赢家审计

原始已平仓top10身份固定于S0，不在各L下重选。区分：

- 实际是否取得原入口、是否在原正常退出前被止损、是否同入口持有至正常退出；未取得原入口单列。
- 仅以原入口fill及原交易路径判断stop是否触及，是隔离触及诊断，不能冒充候选策略利润。
- 原同向区间内候选全部实际交易（含重入）净收益，避免将首次止损视作整段收益永久丢失。

同时报告候选自身新top1/5/10/20收益集中度，严格区分与原始top10身份审计。描述性删除赢家不是可执行回测。

## 选择边界与重现

全部七组原顺序展示，不自动排名或冻结L。比较回撤、水下期、连亏、最大单亏、利润、PF/Sharpe、多空、年度/月份、原赢家保留及既定邻域；不为迎合结果构造权重或扩展网格。
若六组不能同时满足负责人风险/利润取舍，应保留原无止损，不强行添加规则。获负责人审阅并冻结L后，才允许另行授权2022/2023历史验证，不因验证差回选L。
只向指标及执行器传2020—2021数据；原快照时间/零成交量结构核验可覆盖2020—2023，无该后续行情绩效计算；2024+禁读。2020—2023有旧研究复用，不叫独立未见OOS。
