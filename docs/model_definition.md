# 独立斜率模型与统一信号

任务 `S0_FROM_SCRATCH_SLOPE_ESTIMATOR_2020_2023`。本模型不继承任何旧模型、特征、参数、标准化或执行器。

令y[t]=ln(close[t])，N固定候选为[8,16,32,64,96]。时间坐标i=0,...,N−1，斜率单位是每根15分钟K线的对数价格变化。

方法A（端点）：`beta[t]=(y[t]-y[t-N+1])/(N-1)`。只使用首尾两点估计，窗口内若含无效价格则整个指标无效。

方法B（滚动OLS）：`beta[t]=sum((i-i_mean)*(y_i-y_mean))/sum((i-i_mean)^2)`。
利用sum(i-i_mean)=0，实现中减去窗口首值代替均值以改善浮点稳定性，数学上完全等价；每窗口独立求和确保前缀不受整段长度或BLAS路径变化影响。未加平滑、标准化、近零容差或阈值。

N根K线覆盖的K线时长分别为2/4/8/16/24小时；首尾收盘点之间实际相隔(N−1)根，即1.75/3.75/7.75/15.75/23.75小时。

信号是严格斜率符号：正数+1、负数−1、精确0继承上一信号（初始0）。无效值不生成订单、保持上一有效信号记忆和当前持仓。
信号只在窗口末根收盘可用，下一根open执行。空仓首次非零开仓；同向保持；反向先退出旧仓再开新仓。最大一个持仓、不加仓，无中性阈值平仓、确认、冷却、过滤、止损止盈。
末根收盘信号无下一根授权行情时不执行，持仓按末根close标记，无虚构平仓及退出费。

统一先用2020-01-01的96根完整K线预热，首个绩效成交时间2020-01-02 00:00 UTC，使用前一根收盘信号。该公共起点只来自最大候选窗口，不继承旧研究启动规则。2021年界不重置任何模型、信号、持仓或权益。

初始资金10000，固定保证金预算1000、2倍杠杆、成交名义2000；数量=2000/含滑点成交价，费用单独扣，不复利。
方向s=+1多头/−1空头：开仓价=open×(1+s×0.0002)，平仓价=open×(1−s×0.0002)，开仓费=2000×0.0005，退出费=数量×退出价×0.0005。
净收益=s×数量×(平仓价−开仓价)−双边费用；反向是两项执行，不能只算净差仓位。
资金费率、交易所强平、盘口深度、撮合延迟未建模。若固定名义账户不足1000加开仓费，记录shortfall但不暗加资金过滤条件；结果须明确标记不可据此认定实盘可行。
零成交量记录原样保留；在其open假设成交的每项平/开动作均单独输出不确定性，不能称为已证明成交。
