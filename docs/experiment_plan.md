# 执行阶段与审阅边界

1. 在指定基准上新建独立研究分支，归档旧研究，不修改main或原项目。
2. 核验固定SHA256与六列原始行情，保留零成交量记录；新代码只收到2020—2021。
3. 独立实现A端点、B滚动OLS与统一符号信号、下一open执行器、固定名义成本账本。先完成公式、前缀、未来扰动、执行、跨年及末端测试。
4. 只运行预登记10组训练；保存全部交易/执行、权益、年/月/方向、成本拖累、极端交易贡献及邻域，不宣布自动胜者。
5. 对完整10组重复与对账，生成7类图表和所有CSV、元数据、日志及SHA256清单，提交推送研究分支。
6. 本轮立即停止。负责人审阅后指定方法/N，另生成冻结记录（含提交、配置/数据哈希、训练末端仓位和待执行信号），再授权2022—2023验证；验证失败不得回选N。
